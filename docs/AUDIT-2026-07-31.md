## Skipped — Explicit Over-Engineering Decisions

- **`_map_row()` split** — Already uses per-type helpers (`_clean_text`, `_parse_numeric`, `_parse_int`, `_parse_float`, `_parse_bool`, `_serialize_payload`). Further splitting into per-field normalizers would add indirection without benefit.
- **`ScraperFactory` plugin registry** — Only 8 strategies, all in one file. Splitting into a plugin system adds ~150 lines of infrastructure for zero concrete benefit at this size.
- **API response envelope wrapper** — All current endpoints return bare dicts; no mixed `{"data": ...}` patterns exist. Adding wrappers now would break all existing API consumers.
- **Rate limiting middleware** — `slowapi` is not a current dependency. Adding it requires dep approval; flagged as out-of-scope for this audit.
